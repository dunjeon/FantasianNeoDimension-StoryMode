FANTASIAN Neo Dimension — Story Mode

A free, open-source drag-and-drop difficulty change. Fan project. Not made by or affiliated with Square Enix or Mistwalker. Made with Grok by xAI. MIT license.

Download the latest release

Install

  1. Close the game.
  2. Open the zip and drag the FantasianND_Data folder onto the game folder, into the same place as the FantasianND_Data folder that is already there.
  3. Replace the files when asked, then start the game.

The game folder is the one that contains FantasianND.exe. On Steam it is:

steamapps/common/FANTASIAN Neo Dimension/

Nothing else needs to be installed. The same drop works on Windows and on Linux through Proton.

What the menu does

The menu names stay Normal, Hard, and Super Hard.

MenuEnemies
NormalStory. HP 60%, attack 50%, defense 60%, speed −4, experience +50%.
HardEasy. HP 80%, attack 75%, defense 80%, speed −2, experience unchanged.
Super HardThe original Normal enemy stats.

A New Game+ custom enemy slider still scales attack, defense, and speed on top of these tables.

Remove it

In Steam, verify the integrity of the game files. That restores the original tables.
